# Governance policy

## 1. Project leadership and maintainership

- **Enoque Sousa** (`@ESousa97`) is the founder, project lead, and primary maintainer of the Veloryft project.
- The official repository for this project is [enoquesousa/veloryft-hud](https://github.com/enoquesousa/veloryft-hud).

## 2. Decision making and roadmap

The primary maintainer has ultimate responsibility for the direction, quality, and architecture of the project. This includes:

- Setting the project vision, roadmap, and scope.
- Managing software releases, tags, and official binary distribution.
- Reviewing, accepting, or rejecting incoming pull requests, issue reports, and feature proposals.
- Maintaining security standards, licensing compliance, and code quality.

## 3. Contributions and pull requests

Contributions from the community are welcomed and appreciated. However:

- Pull requests are proposals for inclusion into the project and do not guarantee acceptance or merge.
- Submissions will be evaluated against project requirements, security standards, maintainability, architectural fit, and design goals.
- The project maintainer reserves the right to request changes, defer, or decline pull requests that do not align with the goals of the project.

## 4. Forks and downstream distributions

- Under the Apache License 2.0, anyone is free to fork, modify, and redistribute the source code.
- Forks and downstream builds are independent projects and do not represent, speak for, or constitute official builds of the Veloryft project.
- For guidelines on distribution, naming, and re-branding of downstream forks, refer to [TRADEMARKS.md](TRADEMARKS.md).

## 5. Trademark and branding usage

- The name **Veloryft**, brand assets, logos, and associated artwork are protected trademarks and are governed by [TRADEMARKS.md](TRADEMARKS.md).
- Permission to use the source code under the Apache-2.0 license does not grant rights to use the Veloryft trademarks or brand assets for modified distributions or downstream forks.

## 6. Official channels and communication

- Only channels and accounts explicitly listed in this repository (e.g., the official GitHub repository at `https://github.com/enoquesousa/veloryft-hud` and `https://veloryft.com`) are official project channels.
- No third-party forum, chat server, account, or external publication represents the official Veloryft project unless explicitly linked from official channels.
